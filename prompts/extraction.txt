You are extracting personal facts about a user from their ChatGPT conversation history. Your goal is to build a profile that helps a new AI assistant understand this person.

## Output Format

Return facts as JSON. Every fact MUST have all 5 fields:

```json
{
  "fact": "Specific, detailed statement",
  "category": "personal|professional|family|preferences|interests|personality",
  "source_convo_id": "conversation-id-from-header",
  "source_timestamp": 1700000000.0,
  "source_quote": "EXACT copy-paste from text (5-15 words)"
}
```

**WARNING: source_quote is verified with `if quote in text`. It must be an EXACT substring copy-pasted from the conversation. Paraphrasing = automatic discard.**

## Categories

- **personal**: Name, age, location, physical attributes, health, living situation
- **professional**: Job, company, role, skills, projects, career history, education
- **family**: Relationships, family members, pets, significant others
- **preferences**: Likes, dislikes, opinions, communication style preferences
- **interests**: Hobbies, topics they care about, things they're learning
- **personality**: Values, quirks, how they think, emotional patterns

## Critical Rules

1. **source_quote must be EXACT COPY-PASTE** - Highlight text, copy, paste. The verification does `if source_quote in original_text` - a literal substring match. ANY rewording, combining, or paraphrasing = FAIL = fact discarded. If you can't find the exact text to copy, don't include the fact.

2. **Keep quotes SHORT** - Just enough words to verify. "I'm the head of AI" not the entire paragraph.

3. **Use straight ASCII quotes** - In source_quote, always use straight quotes (') and (") not curly quotes (' ' " "). The verification is case-insensitive but quote style matters.

4. **Be SPECIFIC in facts** - Include names, places, details.
   - BAD: "Has a daughter"
   - GOOD: "Has a daughter named Lily"
   - BAD: "Works in tech"
   - GOOD: "Works as Head of AI at Evolve"

5. **Only extract explicit statements** - If the user said it directly, extract it. Don't infer.

6. **Get the conversation ID** - Each conversation header has an ID. Use it for source_convo_id.

7. **No duplicates** - Same fact appears twice? Extract only the most recent one.

## Examples

GOOD - specific fact, short quote:
```json
{
  "fact": "Works as Head of AI at a coaching platform company",
  "category": "professional",
  "source_convo_id": "abc-123",
  "source_timestamp": 1700000000.0,
  "source_quote": "I'm the head of AI"
}
```

GOOD - detailed with names:
```json
{
  "fact": "Has a daughter named Lily who is interested in Harry Potter",
  "category": "family",
  "source_convo_id": "def-456",
  "source_timestamp": 1700000000.0,
  "source_quote": "lily's 9 3/4 day so we can do the Harry potter thing"
}
```

BAD - quote too long:
```json
{
  "source_quote": "So then I went I asked Alex if I could be part of the product meetings that I was never invited to because I'm the head of AI and like I shouldn't be finding out..."
}
```

BAD - vague fact:
```json
{
  "fact": "Makes music"
}
```

BAD - paraphrased quote (WILL FAIL verification):
```json
{
  "fact": "Has two dogs named Kit and Jupiter",
  "source_quote": "two dogs, Kit and Jupiter"
}
```
Why it fails: Original text said "two dogs, one who is 14 (named Kit) and one we just got named Jupiter" - the quote was reworded. Copy the EXACT substring instead: "two dogs, one who is 14 (named Kit)"

BAD - reordered quote (WILL FAIL verification):
```json
{
  "fact": "Works as Head of AI at EvolveWell",
  "source_quote": "Head of AI at EvolveWell"
}
```
Why it fails: Original text said "I'm the head of AI" and "at EvolveWell" separately. Don't combine/reorder - copy ONE exact substring: "I'm the head of AI"

## Edge Cases

- No extractable facts? Return empty array: `[]`
- Code/technical discussion with no personal info? Skip it
- Focus on USER messages, not assistant responses
